# Student Study Planner 📚

## 1. Project Overview

Student Study Planner is a web application designed to help students organize their study schedules, manage academic tasks, and track their learning progress.

## 2. Objectives

* Organize daily study activities.
* Create and manage study tasks.
* Schedule subjects with dates and times.
* Track completed and pending tasks.
* Improve time management and productivity.

## 3. Technologies Used

* HTML — Structure
* CSS — Styling and responsive design
* JavaScript — Application functionality
* Browser Local Storage — Saving tasks locally
* GitHub — Version control and project management

## 4. Main Features

* Student dashboard
* Subject and task management
* Daily study schedule
* Task completion tracking
* Study progress display
* Student profile
* Responsive user interface

## 5. Project Structure

* index.html
* style.css
* script.js
* README.md
* requirements.md
* task-board.md
* workflow.md
* architecture.md
* prototype.md
* test-results.md

## 6. How to Run

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
4. Add study tasks and explore the available features.

##7. Expected Outcome

A simple and user-friendly application that helps students plan their studies and monitor task completion.
